## 11. 缺陷和环境问题

### TEST-DEFECT-001：Go 标准库可达漏洞

- 严重级别：P0，阻断发布。
- 证据：`govulncheck` 报告 GO-2026-6091、GO-2026-6090、GO-2026-6089、GO-2026-5972。
- 影响：涉及 `html/template`、`crypto/tls`、`net/http` 和 `encoding/asn1` 的当前可达调用链。
- 验收：升级项目、Dockerfile 和 CI 到 Go 1.25.13 或更高兼容修复版本；重跑全部门禁、镜像构建和完整栈测试；`govulncheck` 不再报告可达漏洞。

### TEST-DEFECT-002：关闭注册时前端仍展示注册流程

- 严重级别：P1；后端未绕过，但用户体验与业务配置不一致。
- 证据：后端 POST 注册返回 404；浏览器仍显示注册入口和表单，并显示通用 404。
- 影响：关闭公开注册时用户仍被引导到必然失败的流程，且错误信息不可理解。
- 验收：前端读取可信的注册能力配置；关闭时隐藏入口、阻止访问或展示明确说明；增加关闭模式的 API 和 Playwright 测试。

### TEST-ENV-001：golangci-lint 旧路径缓存

- 严重级别：环境问题，不是代码缺陷。
- 证据：首次 lint 引用已经不存在的旧项目目录并误报 6 项；`golangci-lint cache clean` 后同一代码 `0 issues`。
- 后续：项目迁移目录后清理 linter 缓存；CI 使用干净环境。

### TEST-ENV-002：验收脚本复用限流状态

- 严重级别：测试隔离问题，已在本轮修正。
- 证据：复用 Redis 数据卷时 `AUTH-02` 后的正常登录返回 429，套件为 5/11；全新数据卷且限流用例最后执行时为 11/11。
- 修正：普通用户密码改为运行时生成；`AUTH-02` 移到末尾；正式验收使用独立 Redis 数据卷。
